# Runline Studio v0.2

Touch-friendly agility course builder designed as a sister product to Runline.

## v0.2
- Installable PWA / standalone Home Screen mode
- Obstacle width and length resizing
- Adjustable tunnel length and curvature
- Pan by dragging empty course space, dedicated Pan tool, wheel zoom and pinch zoom
- Focus mode with visible Back control
- Course numbers independently draggable; reset position available
- Tablet side drawers reflow the course instead of covering it
- Background image import with opacity control for tracing existing maps
- Optional measured horizontal and vertical axes
- Gamble / Snooker tools: solid red line, dashed red line, red zone and red label
- Editable local course saves
- Download/open portable `.runline` course project files
- PNG/JPG course-map export

## Obstacles
Jump, Snooker red, double, triple, wall, tire, long jump, weave poles, dog walk, A-frame, teeter, tunnel and table.

## Typography
The CSS requests Manifold Extended for identity/headings and Inter for UI text. Font files are intentionally not bundled.

## Install on iPad
Open the GitHub Pages site in Safari, use Share → Add to Home Screen, then launch Runline Studio from the Home Screen.
