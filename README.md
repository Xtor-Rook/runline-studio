# Runline Studio v0.1

A touch-friendly agility course builder prototype designed as a sister product to Runline.

## Included
- Custom field width / length with metres or feet
- Optional grid and snap-to-grid
- Agility obstacle palette: jump, Snooker red, double, triple, wall, tire, long jump, weaves, dog walk, A-frame, teeter, tunnel, table
- Drag / rotate obstacles
- Adjustable tunnel length and curvature
- Course numbers with a–f suffixes and auto-numbering
- Red gamble-line drawing
- Undo / redo
- Zoom, pinch zoom, fit, focus mode
- Editable course title
- Local browser saving and loading
- PNG / JPG export with optional grid and title
- Runline palette and typography hooks (Manifold Extended + Inter fallbacks)

## Run
Open `index.html` in a modern browser. For best iPad behavior, host the folder on a simple static web server or your normal app hosting setup.

## Typography
The CSS requests `Manifold Extended` for identity/headings and `Inter` for UI text. Font files are intentionally not bundled.
